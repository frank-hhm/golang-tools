## 一、局域网互传设置分区（启动默认值落配置）

- **`services/config/config.go`（CRLF，仅精确改）**：`LanShareConfig` 从只有 `BlockExt` 扩为 `Port int` / `Host string` / `AutoStopMin int` / `Pin string`（全 `omitempty`）；`defaultLanShareConfig()` 给 `AutoStopMin:120`；normalize 清洗（端口越界归零、autoStopMin 负值归默认等）。与既有接收优化里建的 `BlockExt` 段合并，不新建整段。
- **`services/app/lanshare.go`**：`SaveLanShareSettings` 签名由 `(blockExt []string)` 改为 `(in config.LanShareConfig)`，一次写回全部 5 字段。
- **`views/tools/settings/index.vue`**：新增「局域网互传」a-card——导航条目 `{key:"lanshare", label:"局域网互传", icon:"IconSend"}`（IconSend 目录存在性已核实）、端口/监听地址/到点自动停/默认 PIN 四控件 + 保存/重载、`loadLanShare`/`saveLanShare` 转调绑定、`watch(activeTab)` 切入懒加载、搜索 skey 登记 4 条。
- **`views/tools/lanshare/index.vue`**：`ctl` 加 `port`；`loadReceivePolicy` 未运行时回填 host/stopMin/pin/port 作启动默认值；`saveReceivePolicy` 传整段 config；`start()` 用 `ctl.port>0?ctl.port:0`。

## 二、FTP⇄term 凭据层归一

- **`tools/ftp/types.go`**：`Connection` 加 `CredID string json:"credID,omitempty"`（关联 term 共享凭据）+ `Passphrase string json:"passphrase,omitempty"`（私钥口令，仅内存短暂存在、不落盘）。
- **`tools/ftp/store.go`**：保存时按 `CredID` 清内联 `PassEnc`（引用凭据就不存本机密码）；导出 `ResolveStored(id)` 供绑定层拿到连接 + 明文密码。
- **`tools/ftp/client_sftp.go`**：拆出 `OpenSessionResolved(c Connection, pass string)` 供绑定层调用；`sshClientConfig` 支持 `ParsePrivateKeyWithPassphrase`（带口令私钥）。
- **`tools/term/credential.go`**：新增导出层 `CredentialSpec{Auth,User,Password,KeyPath,Passphrase}` + `ResolveCredential(id)` + `ResolveHostSpec(id)`（返回含明文的 Host/connectSpec）+ `SaveHostFromForm`。
- **`services/app/ftp.go`（归一桥接，tools 包仍互不依赖）**：`resolveFtpConn(c, pass)` 按 `CredID` 调 `term.ResolveCredential` 把 auth/user/keyPath/passphrase/password 叠加进连接视图；`FtpOpenSession`/`FtpTestConnection` 改走 `ResolveStored → resolveFtpConn → OpenSessionResolved`。
- **`views/tools/ftp/components/ConnectionFormModal.vue`**：加凭据下拉（复用 `../../term/components/CredentialModal.vue`），选凭据时隐藏内联账号/密码/私钥并跳过对应校验；`credSummary` 展示所引凭据。
- **`views/tools/ftp/types.ts`**：`FtpConnection` 补 `credID?`/`passphrase?` 两字段（与 Go json tag 对齐）。

## 三、FTP⇄term 跨工具互跳

- **`services/app/ftp.go`**：`FtpOpenInTerminal(connID)` 把 SFTP 连接导入为终端主机（共享 credID，或把内联密码/私钥升格为 term 凭据）返回 hostID；`TermOpenInSFTP(hostID)` 走 `term.ResolveHostSpec` 取明文规格、同理升格凭据、`ftp.SaveConnection` 返回 connID。
- **`views/tools/ftp/components/ClientPanel.vue`**：dropdown 加「在终端中打开」（`icon-terminal`）→ `openInTerminal` 调 `FtpOpenInTerminal` + `openToolWindow('/tools/term?host=…', '终端连接', {single:true})`；`onMounted` 读 `route.query.conn` 命中即自动连接（接收反向跳转）。
- **`views/tools/term/index.vue`**：dropdown 加「在 SFTP 中打开」（`icon-storage`）→ `onHostAction` 分派 `openInSftp` 调 `TermOpenInSFTP` + `openToolWindow('/tools/ftp?conn=…', '文件传输', {single:true})`；补 `useRoute`/`useToolWindow` 引入；`onMounted` 改 async，先 `await loadHosts()` 再读 `route.query.host` 命中即 `connect`（接收正向跳转）。
- 路由 `tools/term`、`tools/ftp` 均已存在于 `router/modules/base.ts`，无需新增。
