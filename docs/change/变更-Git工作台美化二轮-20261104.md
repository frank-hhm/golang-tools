## 一、诉求

用户反馈 Git 工作台「样式太难看」，截图红框标两处：
1. 主区变更面板改动少时撑成半屏空 bordered 卡片，像没加载完。
2. 点提交后底部文件清单只有 `路径 + 追溯/历史 + +N -M` 纯文字，局促无层次。

## 二、提交文件清单美化（HistoryPane.vue，红框 2）

- **状态色点**：每行行首加 `hf-dot`，由 numstat 增删数启发推色——纯新增绿 / 纯删除红 / 又加又删橙（最常见是修改）/ 二进制灰。`FileDiff` 无 name-status 字段，只能启发，故用色点而非字母，避免把「只有新增行的修改」误标成 A。
- **增删比例条**：`hf-bar` 定宽 52px 槽，内嵌绿段（`addPct`=新增/(新增+删除)）+ 红段按占比铺宽，一眼看改动构成；`title` 悬停显示精确 `+N / -M`。
- **对齐与层次**：`hist-fnum` 定宽 62px 右对齐，数字不再参差；行内 gap 8px、行高 padding 由 `1px` 提到 `3px`；「追溯/历史」合并进 `hd-fhis` 容器（hover 显现，加 opacity 过渡）。
- 新增纯函数 `fstate(f)` / `addPct(f)`，不改数据流、不动 Go 与绑定。

## 三、变更面板留白治理（index.vue，红框 1）

- `.changes-card` 加 `align-self: flex-start; max-height: 100%`：改动少时按内容收高（顶部与满高历史卡对齐），不再撑成半屏空框；改动多时到上限后内部 `overflow:auto` 滚。首轮曾用 `flex:1` 撑满，反而在小改动时暴露大片空白，本轮改为「按需收高 + 封顶滚动」。
