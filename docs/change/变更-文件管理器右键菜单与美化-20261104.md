# 变更-文件管理器右键菜单与美化-20261104

## 诉求

「文件管理器再，美化及完善」。经确认：目标 = **磁盘管理 Disk（本地文件管理器）为主 + 文件查看器 Viewer 轻量风格统一**；
功能 = 右键上下文菜单、网格视图补齐条目操作、地址栏与常用增强、整体视觉美化四项全做。

**纯前端改动，不动 Go 后端、不重生成绑定**：所有条目动作 100% 复用 `disk/index.vue` 已有的
`onRowMore(v, r)` 与工具栏批量函数；「在文件夹中显示」走已就绪的 `DiskOpenInExplorer`
（Windows 对文件 `explorer /select` 定位、对目录直接打开；非 Windows 返回不支持，符合跨平台约束）。

## 一、Disk：列表 + 网格统一右键上下文菜单

文件：`frontend/src/views/tools/disk/index.vue`

- 列表 `a-table` 加 `@row-contextmenu="onRowContext"`；网格块 `.g-item` 加
  `@contextmenu.prevent.stop="onRowContext(r, $event)"`——补齐网格此前完全没有的条目操作入口。
- 菜单照 portman/procman 既有口径自绘：`ctx-mask`（fixed 遮罩，点击/右键关闭）+ `a-menu.ctx-menu`
  （fixed 定位）。`showCtxMenu` 先按点击位置显示，`await nextTick()` 后用真实 `offsetWidth/offsetHeight`
  夹回视口，不靠估计尺寸。
- `onCtxClick(key)`：批量类（复制/剪切/删除/永久删除/压缩）走 `selectedPaths`，单行类（打开/改名/属性/
  查看器/系统程序/终端/在文件夹中显示/大小/文档系列/解压）走 `ctx.row`，其余委托 `onRowMore`。
- **多选语义**：右键未选中的行 → 单选它；右键已在多选集内的行 → 保留整个多选集，批量动作自然命中全部，
  菜单项带「（N 项）」提示（`ctxBatch`/`ctxCount`）。
- 虚拟「打开」图标按 `isDir` 用 `icon-folder`/`icon-file`，不引入未注册图标。
- Esc 关闭：`onMounted/onUnmounted` 注册 `window` `keydown`。
- 保留原「…」下拉与三个行内按钮不删，右键只是新增同等入口。

## 二、Disk：地址栏与常用增强

- 路径栏面包屑后加可编辑地址输入 `addrInput`（回车 `enter()` 跳转，移植 Viewer `vp-addr` 做法），
  `watch(current)` 同步，改写后回车才跳转。
- 加「复制当前路径」按钮 `copyCurPath()`：`navigator.clipboard.writeText(current)`，非安全上下文失败给
  `Message.warning` 兜底。
- 「打开父目录」不新增——`goUp` 与面包屑已覆盖。

## 三、Disk：视觉美化

- 列表选中态：不再整行刷主色，改中性淡底 `--color-fill-3` + 名称列 `::before` 左侧短竖条
  （`rgb(var(--primary-6))`，圆角 `var(--base-radius-small)`），与 Git 仓库项、docspace 树节点一套语言。
- 网格块：hover 淡底 `--color-fill-2`、选中 `--color-fill-3` + 左上短竖条，去掉原来的整圈主色边框；
  过渡统一 `background-color .15s`。
- 右键菜单样式 `--color-bg-popup` + `border 1px var(--color-border-2)` + `border-radius var(--base-radius-default)`
  + `box-shadow 0 6px 18px rgb(0 0 0 / 16%)`；危险项 `.ctx-del` 用 `rgb(var(--danger-6))`。

## 环境提醒（本轮踩到，非代码问题）

- **vite/rolldown 需要 Node 20+**：本机 nvm 默认停在 16.20.2 时，`node scripts/build.mjs` 的 vite 阶段直接崩在
  `import { styleText } from "node:util"`（该导出 Node 20.12+ 才有）。本轮用会话内临时把 v20 前置到 PATH 构建通过；
  交付/CI 请确认 node ≥ 20。
- **`wails_windows_amd64.syso` 缺失会让 `go build .`（桌面）失败**：这是 wails 生成物、不入库。本轮用
  `wails3 generate syso -arch amd64 -icon build/windows/icon.ico -info build/windows/info.json
  -manifest build/windows/wails.exe.manifest -out wails_windows_amd64.syso` 重新生成后桌面构建转绿。
