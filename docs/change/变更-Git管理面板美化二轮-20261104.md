# 变更-Git管理面板美化二轮-20261104

> 状态：**已执行到构建层**（vue-tsc + vite build exit=0，纯前端零 Go 改动）。悬停/选中态的实际观感需人工在 GUI 里瞄一眼（本机无图形回归环境）。

## 一、范围

1103 首轮美化（变更区撑满、空分组折叠、状态码色块、短竖条选中态等）之外的二轮打磨，集中在 [views/tools/git](../frontend/src/views/tools/git/index.vue) 主页与历史面板，并清偿按钮规范欠账。

## 二、改动点

- **`index.vue`**：
  - 仓库卡头两个图标钮去掉 `type="text"`（按钮规范禁用），改默认形态 + `#icon` 插槽，与主页「全部工具」方块图标钮同款；
  - 仓库行首新增 **状态圆点** `.repo-dot`（8px 灰环，`--gray-4`）：选中仓库时点亮成主色实心 + 2px 微光晕（`rgba(--primary-6,.18)`），呼应右侧历史面板 DAG 节点的视觉语言；
  - 左侧空态从一行小字升级为居中的「icon-folder + 暂无仓库 + 引导句」两段式（读取中态保持纯文字）。
- **`components/HistoryPane.vue`**：选中提交行补**左缘短竖条指示器**（3px 主色、右侧两角圆角、垂直居中，与仓库列表/nginx 实例条同一口径），标题同步点亮主色加粗；hover 轻底维持不变。
- **`StashModal / BranchModal / RemoteModal / TagModal`**：表格行内操作钮全部 `type="text"` → `type="secondary"`（规范允许的弱化形态），`status="danger"` 语义保留；grep 核实 git 目录已无 `type="text"` 残留。

配色全部取 Arco CSS 变量三元组（`rgb()/rgba()` 包裹），圆角取 `--base-radius-small / --border-radius-full`，无硬编码色值。

## 三、验证到哪一层

- `vue-tsc --noEmit`（Node v22.23.2）exit=0；`vite build` exit=0。
- Go 侧零改动，无需重生成绑定；`/Tools` 忽略规则不涉及本轮文件。
- **未做**：暗黑模式下的圆点光晕强度、secondary 按钮在表格里的密度观感、历史行短竖条与 canvas DAG 的重叠视觉——均需人工 GUI 确认。
