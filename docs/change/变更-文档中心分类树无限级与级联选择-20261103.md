# 文档中心 · 分类树无限级 + a-cascader 选父级 + a-tree 连线

> 状态：已交付（前端，vue-tsc + vite build 双 0；未做真机浏览器目测）
> 日期：2026-11-03
> 范围：纯前端，`frontend/src/views/tools/docspace/index.vue`；后端 `Category.Parent` 本就支持无限嵌套，无 Go 改动

## 诉求

1. 分类级别无限级（原树渲染有 `depth < 5` 层数上限）；
2. 「新建分类」的父分类选择改用 `a-cascader`【check-strictly】（原为平铺 `a-select`，重名分类分不清层级，见图2）；
3. 左侧分类树用 `a-tree` 显示连线（见图3）。

## 改动

- **无限级**：`treeData` 的递归 `build` 去掉 `depth < 5` 上限，改为 `seen:Set` 防脏数据成环导致无限递归；新增 `catOptions` computed（`value=id / label=name / children`，同样无限级 + 环保护）供两处 cascader 共用。
- **a-tree 连线**：左侧 `<a-tree>` 加 `show-line`。
- **a-cascader 选父级**：「新建分类 → 父分类」与「纳管文件 → 分类」两处 `a-select` 换成 `<a-cascader :options="catOptions" check-strictly allow-clear>`。核实 Arco `checkStrictly` 在单选模式下给每个节点渲染 radio（`cascader-option.js` `checkStrictly && !multiple` → `Radio`），即可选中任意一级。
- **类型对齐**：`catForm.parent` / `itemForm.category` 由 `string` 改 `string | undefined`（cascader 清空回吐 undefined）；`openAddItem` 与新建后重置同步归一为 `undefined`；提交仍 `|| ""` 传后端。
