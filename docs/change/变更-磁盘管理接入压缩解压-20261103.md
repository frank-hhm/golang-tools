> 范围：纯前端，`frontend/src/views/tools/disk/index.vue`；压缩/解压内核 `tools/archive` 与 `Archive*` 绑定、`archive:progress` 事件、任务中心登记均现成，无 Go 改动

## 诉求

磁盘管理页增加压缩/解压入口，并排查还有哪些地方该加。

## 改动

- **两个入口**：工具条「更多」+ 每行「⋯」菜单各加「压缩为压缩包」「解压到同级文件夹」。
  - 压缩：工具条按多选（`selectedPaths`）批量、行菜单按单行；解压仅对 zip/tar.gz/tgz 显示（`isArchiveFile` 按 `FormatFor` 口径判后缀）。
- **压缩小窗**：格式（zip/tar.gz）+ 级别（1~9）+ 输出名 + 输出目录（默认当前目录）；打开时用 `ArchiveScan` 预扫描显示项数与字节、`ArchiveSuggestName` 预填成品名（剥扩展）。
- **发起**：`ArchiveCompress(opts)` / `ArchiveExtract({paths:[归档], outDir:""})`——解压 `outDir` 留空即引擎「解到同级同名文件夹」语义。进度/取消走 `archive:progress` → 右下角任务中心，与压缩工具页、系统右键同一套，磁盘页不重复做进度 UI。

## 其余入口的评估（"是否也要加"）

- **文件查看器 viewer**：已能进压缩包浏览单条 + 解压单条（`ArchiveListEntries`/`ArchiveExtractEntry`），覆盖"看归档内容"场景；整包解压磁盘页已给。→ 不改。
- **文档中心 docspace**：本机条目行「操作」加「压缩」→ `ArchiveCompress({paths:[item.path], format:"zip", outDir:""})` 就地打包（仅 `src==='local'` 显示，远端条目不适用）；操作列宽 430→470。vue-tsc = 0。
- **云盘 / FTP 传输页**：对象是远端文件，`tools/archive` 只吃本地路径，需先下载再压。→ 不适用，不加。
- 结论：**磁盘管理页是本地压缩/解压的正解落点**，已完成；其余入口现状合理。
