# 变更-文档管理面板美化-20261103

## 诉求

「美化文档管理面板」。反馈截图是暗色模式下的文档中心（docspace），能直接看出四类问题：
顶部统计卡最右一张被窗口切掉、左侧分类树靠字符一样的连接线撑层级且文字发灰、
筛选行控件高矮不齐、卡片与批量条在暗色下层次糊成一片。

## 改了什么

### 顶部工具栏 / 统计条

- `index.vue`：库目录从「库目录：一长串裸路径」改成 **标签 + 窄底色框**（`.hint-k` / `.hint-path`），
  路径超 280px 走省略号，完整值仍在 `title` 里。原来那串路径会把整条工具栏顶宽，
  窗口一窄就换行，主操作按钮跟着抖。
- `StatsBar.vue`：`grid-template-columns` 的下限改成 `minmax(min(190px, 100%), 1fr)`，
  并给 `.ds-stats > *` 补 `min-width: 0`。
  **这就是截图里第 5 张卡被切掉的根因**：grid 子项默认 `min-width: auto`，
  而指标卡的明细行是 `white-space: nowrap`，窄列时内容把列顶宽，整条统计栏就比容器宽了。

### 左侧分类树

- 关掉 `show-line`。Arco 的连接线在暗色下几乎看不见，调亮又像字符画；
  缩进 + hover/选中态本身足够表达层级。
- 补齐了模板里用了、样式里却完全没有的 `.left-head` / `.left-title`（标题小字号 + 字距，「新建」链接右靠）。
- 节点：行高与圆角统一、字号 13px、正文色（原来继承 Arco 默认的小字灰）；
  hover 才给 `--color-fill-3` 底色；选中态沿用 MySQL 页对象树那套口径
  （中性底色 + 加粗 + 正文色），再叠一根 3×14px 的主色短竖条，不整块刷主色。
- 侧栏底色改 `--color-fill-1`，与右栏 `--color-bg-2` 拉开一层；`.body` 补 1px 描边，
  暗色下主体区不再和页面背景融成同一块黑。

### 筛选行

- 搜索框从写死的 `max-width: 280px` 内联样式改成 `.ds-search`（`flex: 1 1 220px; max-width: 320px`），
  窄窗先收缩、宽窗不至于过长；标签筛选走 `.ds-filter-select` 固定 150px。
- 「只看缺失」与视图切换之间加一条竖分隔，两组职责不同的控件不再挤成一排。

### 网格卡片（`DocGrid.vue`）

- 缩略图区加一层 135° 斜纹底（`rgba(128,128,128,.07)`，中性灰所以两套主题都不刺眼），
  没有图片时不再是「一个图标浮在死黑上」；类型图标补 `drop-shadow` 把它托起来
  （选择器落在 `common-file-icon` 的真实根元素 `.w11-icon` 上，它是内联 SVG 不是 div）。
- 类型徽标加字重、字距与投影，白字在彩色底上更立得住。
- 操作条补 `--color-fill-1` 底色，卡片「缩略图 / 信息 / 操作」三段层次分明；
  选中态在原 1px 内描边之外叠上 `--shadow-2-bottom`。
- 空态从一句「没有符合条件的条目」改成两行：说清可以怎么退出去筛，
  以及「纳管文件」才是从零开始的入口。

### 表格视图 / 批量条

- `DocTable.vue`：表头给 `--color-fill-2` 底 + 正文色加粗。暗色下 Arco 默认表头与表体同色，列名靠不住。
- `BatchBar.vue`：底色从 `rgba(var(--arcoblue-1), .6)` + `arcoblue-3` 描边改成
  以主色为基准的低透明度叠加（0.08 底 / 0.32 描边）。
  原写法只在浅色下成立——暗色里 `arcoblue-1` 是深藏蓝，选中后整条批量栏变成一块压暗的脏色。

## 没有动的

统计口径、排序逻辑、选中集单一事实源、`rowOps` 操作清单、分页归属全部原样；
`KindChips` 的选中态本来就符合「描边走主色、不整块填高饱和」，没改。
本次纯样式与两处模板结构调整（去 `show-line`、空态插槽），不发新的绑定方法调用，
所以后端与 `frontend/bindings` 一律未动。

## 验证到哪一层

- `node scripts/build.mjs`（内含 `vue-tsc --noEmit` + `vite build`）通过，`frontend/dist` 已重建。
- `go build .`（Windows 桌面）与 `GOOS=linux GOARCH=amd64 CGO_ENABLED=0 go build -tags server`
  均 0 退出码（新 dist 已 embed 进去）。
- **没有做浏览器端到端复验**：树的选中短竖条、暗色下斜纹底的观感，
  都是按 Arco 类名与既有页面口径写的，实际渲染效果需要打开页面确认。

## 部署提醒

`frontend/dist` 不入库。服务器上要看新样式，必须先 `cd frontend && npm run build` 再重新构建二进制，
否则页面还是旧的。
