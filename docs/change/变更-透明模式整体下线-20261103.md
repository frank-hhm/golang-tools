# 透明模式（Glass 材质）整体下线

> 状态：已交付（删除，六项校验全 0；未做浏览器端到端复验）
> 日期：2026-11-03
> 范围：`services/config`、`services/sysx`、`services/app`、`main.go`、`frontend/src/{styles,utils,router,components,views}`、`frontend/bindings`

## 诉求

「删除透明的配置及 glass.scss，不需要了」。既然材质层与配置项都不留，为它服务的
原生玻璃链路（DWM 背板声明、能力位、协商绑定、对照测试窗）就成了无人调用的死代码，
而且留着会让主窗/工具窗仍以 `Translucent + Acrylic` 建窗——页面侧再没有对应的实色/透明
切换，只剩风险没有收益，所以整条链路一起摘除，而不是只删样式文件。

## 删掉的东西

**前端（材质与入口）**

- `styles/glass.scss`（含工作区里遗留的 `glass copy.scss`）与 `styles/index.scss` 里的 `@use`：
  两态（`on` 应用内磨砂 / `native` 原生透视）的全部材质规则一并消失，页面回到 Arco 实色底。
- `utils/theme.ts`：`GLASS_STORAGE_KEY` / `currentGlass` / `applyGlass` / `refreshNativeGlass` /
  `bindGlassFocus` / `syncGlassFromConfig` 全删，文件只剩主题那一半；顺带去掉因此空转的
  `Window`、`GoToolsBindings`、`loadCaps` 三个导入。
- `utils/caps.ts`：`nativeGlass` 默认值与 `isNativeGlass()` 删除（`nativeWindows` 保留，它管的是
  「能不能弹原生窗口」，与玻璃无关）。
- 设置页「启用透明模式」表单项、材质标签、能力位文案、系统透明效果告警、`SEARCH_INDEX` 条目、
  `.glass-warn` 样式，以及 `form.general.glass` 在类型/默认值/`load()` 里的三处字段。
- 组件测试台的「原生玻璃透明（对照测试窗）」项与 `openGlassTest`；`/widget/glasstest` 路由与页面。
- 主页时钟的 `face-color` 从 `var(--glass-clock-face, …)` 退回 `var(--color-bg-2)`，
  `canvas-clock` 的 MutationObserver 不再监听 `data-glass`。

**后端（原生层与能力位）**

- `services/app/glass_windows.go` / `glass_other.go` 整文件删除（Acrylic/Mica 背板切换、玻璃诊断、
  对照测试窗）。`services/app/app.go` 随之删掉 4 个绑定方法 `ApplyNativeGlass` / `SetGlassBackdrop` /
  `OpenGlassTestWindow` / `GetGlassDiagnostics`、`SupportsNativeBackdrop()` 与 `glassWindowEligible()`。
- `main.go` 主窗与 `OpenToolWindow` 工具窗的建窗期声明（`BackgroundTypeTranslucent` +
  `BackgroundColour RGBA(0,0,0,0)` + `Windows.BackdropType = Acrylic`）删除，两种窗口都回到 Solid 底。
- `services/sysx`：`Capabilities.NativeGlass` 字段、`Glass()` 方法、`String()` 里的 `glass=` 段，
  以及平台探测文件 `glass_windows.go` / `glass_other.go`（`backdropSupported()`）与那条
  「NativeGlass 蕴含 NativeWindows」的单测。`NativeWindows` 与其余能力位不动。
- `services/config`：`GeneralConfig.Glass` 字段删除。老配置文件里残留的 `"glass": true` 会被
  `encoding/json` 当未知字段忽略，不需要迁移脚本，也不会报错。
- 绑定重生成：`wails3 generate bindings -clean=true -ts -i`（v3.0.0-beta.12，352 packages /
  655 methods，比之前少 4 个即删掉的那 4 个）；`bindings/Tools/services/sysx/models.ts` 回到无
  `nativeGlass` 的状态。
