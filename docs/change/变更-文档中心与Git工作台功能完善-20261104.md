## Git：新增提交历史面板

- `services/app/git.go` 新增绑定方法 `GitLog(repo string, limit int)`，转调已写好却一直没暴露给前端的
  `gitcmd.Log`（`tools/gitcmd/log.go`）。`limit<=0` 走引擎默认 200 笔。方法跨平台存在，不藏 build tag。
- 新建 `frontend/src/views/tools/git/components/HistoryPane.vue`：按 lane 取色 + 缩进画最近提交，
  色点、相对时间、refs（tag/head/remote/local）标签，点击展开该笔改动的文件列表，
  复用既有 `DiffModal` 看某笔某文件的 diff。
- `frontend/src/views/tools/git/index.vue`：变更区与历史面板并排（`.mid-row`），提交 / 同步成功后
  `histRef.value?.load()` 刷新历史。
- 规范修正：文件行操作按钮由 `a-button type="text"` 改为 `a-link`；硬编码圆角改 `var(--base-radius-*)`。

## docspace：分类重命名 / 删除

- `tools/docspace/store.go`
  - 修 `RemoveCategory` 的子分类孤儿 bug：原实现只管条目不管子分类，删父分类后子节点的 `Parent`
    仍指向已删 id，前端建树时它们成孤儿消失。现改为**子分类上提一级**（`Parent` 改挂到被删分类的父级），
    其下条目退为未分类，磁盘文件本体不受影响。
  - 新增 `RenameCategory(id, name)`：trim 后为空报错；只改 `Name` 不动 `id`（id 是条目外键，动了会牵连引用）。
- `services/app/docspace.go` 新增绑定 `DocSpaceRenameCategory(id, name)`，跨平台存在。
- `tools/docspace/docspace_test.go`：`TestStoreCategoryAndItemLifecycle` 补 RenameCategory 与
  「删父分类子分类上提」断言，测试 PASS。
- `frontend/src/views/tools/docspace/index.vue`
  - 分类树 `#title` 插槽给真分类挂右键菜单（遮罩 + fixed 定位的 `a-menu`，照 MySQL 对象树既有口径），
    支持**重命名 / 新建子分类 / 删除**；虚拟节点（「全部 / 未分类」，key 以 `__` 开头）不给菜单。
  - 重命名走独立 modal；删除走 `Modal.confirm`，若正停在被删分类上剪回 `__all__` 再 `reload()`。
  - 顶栏与侧栏两个「新建」入口统一走 `openCatModal()`，开弹窗前清 `parent`，避免普通新建
    默默继承上次右键带来的父分类。
  - Esc 关闭菜单，视口钳制防止贴右下角溢出。
