## 1. 决策摘要（已与用户确认）

| 维度 | 取定的做法 | 明确不做 |
|---|---|---|
| 范围 | 对象存储三家：**阿里 OSS + 腾讯 COS + 通用 S3**（MinIO/七牛/华为 OBS/AWS 皆可） | 腾讯微云（个人网盘纯逆向、QQ/微信登录+风控+私有分块协议，性价比最低，只可能验到 mock）——**本批搁置** |
| 签名 | 手写原生签名，stdlib HMAC-SHA1/SHA256，不引第三方云 SDK | 引 aliyun-oss-go-sdk / tencentcloud-cos-go-sdk（重、拽依赖、违背仓库惯例） |
| 代码结构 | 一个 `objectstore.go` 通用基座（S3 风格 list/get/put/copy/delete/head）+ 可插拔 `signer`；OSS 用 `ossSigner`(V1 HMAC-SHA1)，COS 与通用 S3 共用 `s3Signer`(AWS SigV4) | 三家各写一套完整 Provider |
| 凭证存储 | `bucket/endpoint/region` 存 `Account` 非敏感字段（回前端可显示）；`AccessKeyId/AccessKeySecret` 进 `tokenBlob` 加密（DPAPI/0600），永不回前端 | 全加密（列表/多 bucket 管理拿不到信意）；明文存 AK/SK |
| 添加流程 | 对象存储账号创建即填全（无 OAuth 授权码流程）：一步 `CloudAddObjectStore(kind,label,bucket,endpoint,region,akID,akSecret)` | 沿用粘贴式 `SetCredential`（不适配多字段） |

## 2. 内核：`tools/clouddrive/` 新增三个文件（跨平台零 cgo，带 go test）

### `objectstore.go`（通用对象存储 Provider 基座）
- `type objectStore struct { acctID string; hc *http.Client; bucket, endpoint, region string; signer signer }`
- 语义映射（`Entry.ID` = 完整 object key，即路径）：
  - `List(dirID)`：`GET /?prefix=<dirID/>&delimiter=/` → `CommonPrefixes` 归目录（IsDir=true）、`Contents` 归文件；`dirID` 空=根。
  - `Mkdir(parent,name)`：`PUT <parent/name>/` 零字节（虚拟目录）。
  - `Rename(id,new)` / `Move(id,dst)`：服务端 `PUT` + `x-amz-copy-source`（同 bucket 内 copy）→ `DELETE` 原 key。
  - `Delete(id)`：`DELETE <id>`。
  - `ShareLink(id)`：生成预签名 GET URL（用 signer 的 `presign`，默认有效期 24h）。
  - `Open(id)`：`GET <id>` 流，`size` 取 `Content-Length`。
  - `Upload(parent,name,r,size)`：`PUT <parent/name>`（本批整段缓冲单 PUT，与存量三家一致；分块续传留后续）。
  - `Quota`：OSS 走 `GET /?stat` 解析 `Storage`；COS/S3 无统一配额 → 返回 `{0,0}`（前端 Total=0 即不显总量，接口已支持）。
  - `Test`：`GET /?max-keys=1`（HEAD bucket）探活。
- `Name()` 按 kind 返回「阿里云 OSS / 腾讯云 COS / S3 兼容存储」。

### `signer.go`（签名可插拔）
- `type signer interface { sign(req *http.Request, payloadHash []byte) error; presign(method, key string, expiry time.Duration) (string, error) }`
- `ossSigner`：OSS 原生 V1 —— `Authorization: OSS <akid>:<base64(hmac-sha1(secret, stringToSign))>`，`stringToSign` 含 VERB/Content-MD5/Date/CanonicalizedOSSHeaders/Resource。
- `s3Signer`：AWS Signature V4 —— HMAC-SHA256 派生 signing key（`credential scope = date/region/service/aws4_request`），COS 用 `service="s3"` + 其 region（如 `ap-guangzhou`）、通用 S3 用配置 region。**COS 与 S3 共用这一个 signer，只差 endpoint/region 默认值。**

### 三个注册文件（各 `init()` 里 `register`）
- `oss_aliyun.go`：`KindAliyunOSS="aliyun_oss"`，endpoint 默认 `<region>.aliyuncs.com`，挂 `ossSigner`。
- `cos_tencent.go`：`KindTencentCOS="tencent_cos"`，endpoint 默认 `cos.<region>.myqcloud.com`，挂 `s3Signer`。
- `s3.go`：`KindS3="s3"`，endpoint 用户自填（MinIO/OBS/七牛/AWS），挂 `s3Signer`。
