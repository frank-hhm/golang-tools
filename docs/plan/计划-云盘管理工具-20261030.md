## 1. 核心：`tools/clouddrive/`（新包，跨平台零 cgo，必须带 go test）

### `provider.go`（接口与模型）
```go
type Entry struct { ID, Name, Path string; IsDir bool; Size int64; MTime, MIME, ThumbURL string }
type Quota struct { Used, Total int64 }
type Provider interface {
    Name() string
    Test(ctx) error
    List(ctx, dirID string) ([]Entry, error)
    Mkdir(ctx, parentID, name string) (Entry, error)
    Rename(ctx, id, newName string) error
    Move(ctx, id, dstParentID string) error
    Delete(ctx, id string) error
    ShareLink(ctx, id string) (string, error)
    Open(ctx, id string) (rc io.ReadCloser, size int64, err error)   // 下载源
    Upload(ctx, parentID, name string, r io.Reader, size int64) (Entry, error)
    Quota(ctx) (Quota, error)
}
```
- `Open` 返回流（供下载引擎或跨盘转存消费）；`Upload` 收流（跨盘转存把源 `Open` 接到目标 `Upload`）。size 未知传 -1，适配器按各家能力决定是否需缓冲（Google resumable 可分块；阿里/百度上传需 size，跨盘转存到这两家时先落临时文件再传，见 §4）

### `registry.go`
- `Register(kind string, factory func(Account) (Provider, error))`；`New(acct)` 按 `acct.Kind`（`google|aliyun|baidu`）构造

### `google.go`（官方 Drive v3 + OAuth2）
- 列表 `files.list?q='<id>'+in+parents`、下载 `files/{id}?alt=media`、上传 resumable、增删改 `files.create/update`、分享 `permissions.create`
- OAuth2：`golang.org/x/oauth2`（若不在依赖树则引，属 Google 官方必需）。桌面：本地 `127.0.0.1:随机端口` 回调监听自动收 code；无头面板：打印授权 URL，用户授权后**粘贴回跳 URL/code** 换 token。`client_id/secret` 由用户在设置里填自己的（不内置，避免泄露/轮换）。access+refresh token 存 cred，过期自动 refresh

### `aliyun.go`（refresh_token）
- 授权：用户在阿里开放平台扫码授权拿 `refresh_token`（粘贴进设置）；`POST /token` 用 refresh_token 换 `access_token`（自动续期）
- 文件：`/v2/file/list`、`/v2/file/get_download_url`、`/v2/file/create`(upload-info)+OSS PUT+`/v2/file/complete`、`create_folder`、`update`(rename/move)、`delete`。端点与字段以现网为准，封装在适配器内，失效只动这一处

### `baidu.go`（BDUSS cookie）
- 授权：粘贴 `BDUSS`（+ `STOKEN` 视需要）
- 文件：`xpan/file?method=list`、`filemetas` 取 `dlink` 下载（带 `access_token`/UA，**第三方限速**如实提示）、`superupload` 分块上传、`fileManager` rename/move/delete、分享 `share/...`。BDUSS 走 `Cookie` 头，存 cred

### `store.go`（账号表，照 ftp/store.go）
- `<data>/clouddrive/accounts.json`：`Account{ID,Kind,Label, ...非敏感}` + `SecretEnc`（token/BDUSS 密文，`sysx.NewCred`）；回前端的 `AccountView` **不含密文**。增删改 + 并发锁

### `transfer.go`（云→云跨盘转存）
- `Copy(src Provider, srcID string, dst Provider, dstParentID, name string)`：`src.Open` → `io.Copy` 到 `dst.Upload`（目标需 size 时先流式落 `appdirs.Data("clouddrive")/tmp` 再传）。进度事件 `cloud:progress`（已传字节/总字节/速度），`context` 可取消

- `CloudDownload` 改为 `AddSource("cloud", {acct,file})` 投递进引擎，**返回值从落盘路径变任务 id**；进度改走引擎 `download:progress`，与 HTTP 任务同表管理（队列/暂停/取消/限速/持久化）。流不支持 Range，重启续传=整段重下（如实）。
- 详见 `变更-云盘下载接入下载器引擎-20261111.md`；验证：双 Go 构建+vet+downloader(含 stream 9 例)/clouddrive 单测+vue-tsc 均 0，Linux 交叉编译因本环境沙箱未跑。
