- **关窗停服务的真因**（`wails v3.0.0-beta.12`）：`webview_window_windows.go` WM_CLOSE → 无 hook 时默认 `WindowClosing` 处理器销毁窗口 → `application_windows.go:343 unregisterWindow`：**当 windowMap 为空且未设 `Windows.DisableQuitOnLastWindowClosed` 时 `PostQuitMessage(0)`** → 进程退出 → lanshare 端口随进程死。当前 `main.go` 的 `WindowsOptions` 未设该字段（默认 false）。主窗口有 `setupCloseToTray` 拦截（隐藏不销毁），但**独立工具窗（`OpenToolWindow` single:true）无任何 WindowClosing 拦截**，关闭即销毁；一旦它成为最后一个窗口（或与之关联的销毁竞态），进程退出，服务停。
- `frontend/src/store/modules/tasks.ts`：全局订阅 `task:update`，`lanshare:progress` 产的 Task 已能进台账。`<task-hub>` 组件（浮标+抽屉）**只挂在 `layouts/index.vue`（主窗口）**；`BlankLayout.vue`（工具窗）没有 → 在独立互传窗里看不到跨页接收进度，这是 #2 的前端缺口。
- `frontend/src/views/tools/lanshare/index.vue` L688-701：`Events.On("lanshare:progress", …)` 每来一个事件就 `refreshGrants/Links/Inbox/Sessions` 全量扫盘、且忽略事件 payload——接收中会高频空扫，live 百分比不跟手。

## 2. #3 关 webview 服务不停（`main.go`）

在 `application.Options.Windows` 设 **`DisableQuitOnLastWindowClosed: true`**。这样关闭任意/全部窗口都不会 `PostQuitMessage`，进程与 tray 存活，lanshare 服务继续后台跑；真正的退出只走 `RealQuit`（托盘"退出"，已置 `quitting` 并 `app.Quit()`）。不新增工具窗的 WindowClosing 拦截（保持"关窗即销毁 webview、省内存"的既有语义），仅把进程生命周期与窗口生命周期解耦。

## 3. #1 接收类型黑名单（可配置，默认全收）

### 3.1 `tools/lanshare/access.go`
- 包级 `blockMu sync.RWMutex` + `blockExt map[string]bool`（键为小写、带前导点）。
- `SetBlockExt(exts []string)`：归一（TrimSpace、小写、去重、补前导点、忽略空/纯点），整体替换。空切片 = 全收。
- `uploadBlocked(name)`：`strings.ToLower(filepath.Ext(name))` 命中 `blockExt` 则 true；默认（未注入/空）恒 false。
- 不改 `sanitizeName` 的路径穿越防护。调用点（server.go / upload_session.go）签名不变。

### 3.2 `services/config/config.go`
- 新增 `LanShareConfig{ BlockExt []string json:"blockExt,omitempty" }`。
- `AppConfig` 加指针字段 `LanShare *LanShareConfig json:"lanShare,omitempty"`。
- `defaultLanShareConfig()` 返回 `&LanShareConfig{}`（空黑名单=全收，与"默认全类型"一致；老配置无段等价全收）。
- `LanShareSection(cfg)` / `LanShareCfg()` 兜底。
- `normalizeLanShareConfig(cfg)`：nil 跳过；否则清洗每项（小写、补点、去重、去空），结果回写。在 `normalizeConfig` 末尾调用。
- `LoadAppConfig` 内补 `if loaded.LanShare != nil { cfg.LanShare = loaded.LanShare }`。
- `DefaultConfig()` 里加 `LanShare: defaultLanShareConfig()`。

### 3.3 `services/app/lanshare.go`
- `LanShareSettings() config.LanShareConfig` → `config.LanShareCfg()`。
- `SaveLanShareSettings(blockExt []string) error` → `config.Update` 写 `cfg.LanShare.BlockExt` → 成功后 `ApplyLanShareConfig()` 回灌。
- `ApplyLanShareConfig()`：读 `config.LanShareCfg()`，`lanshare.SetBlockExt(d.BlockExt)`。

### 3.4 `main.go`
- 在 `lanshare.SetEmitter(emit)` 附近调 `appsvc.ApplyLanShareConfig()` 完成启动期回灌。

### 3.5 危险类型常量（前端）
"一键填入"用的常见危险类型列表放前端（与后端旧列表对齐：exe dll bat cmd com msi scr vbs js jse wsf wsh ps1 psm1 lnk sh desktop jar reg）。后端不再有默认黑名单，安全默认改由用户点按钮填。
