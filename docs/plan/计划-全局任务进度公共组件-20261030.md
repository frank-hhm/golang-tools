## 一、背景与目标

进度条目前**至少 8 处各画各的**，形态/文案/状态映射不统一：

| 引用点 | 现状 |
|---|---|
| `components/business/task-hub/index.vue` | 抽屉条目套 `common-item-card` + 内联 `a-progress pct/100` + 自绘浮标细条 |
| `views/tools/siteclone/index.vue` | `a-progress :percent :status` |
| `views/tools/archive/index.vue` | `a-progress :percent :status` |
| `views/tools/ftp/components/TransferQueue.vue` | `a-progress percent(t)/100 :status` |
| `components/business/docker-images/index.vue` | 拉取 `a-progress pullPct/100 mini show-text=false` |
| `views/tools/php/index.vue` / `views/tools/mysql/LocalServicePanel.vue` | 安装进度 `a-progress percent/100 mini` |
| `views/tools/download/index.vue`（**规划中**） | 每任务详情/列表行 |

目标：抽一个**全局公共组件 `common-task-progress`**，把"名称 + 速度 + 整宽进度条 + 右对齐操作"这套任务行统一，各处引用；**纯前端、无 Go、无绑定、无新依赖**。

## 二、决策摘要（含对"卡片/列表/下划线"的定夺）

| 维度 | 取定的做法 | 明确不做 |
|---|---|---|
| 形态 | **列表项（铺满）**，纵向三段：头行(名称↔速度) / 整宽进度条 / 操作行(靠右) | 自带卡片外壳（外壳仍归 `common-item-card`，遵守"外壳归 item-card、内容归调用方"分工） |
| 卡片 vs 列表 | `variant`：`plain`（独立块，自带内边距，直接铺进抽屉/列表）/ `bare`（嵌进 `common-item-card` 内，不加额外外框） | 再造一套卡片皮肤 |
| 下划线 | `divided` prop，默认 true → 项底部 1px `--color-border-2` 分隔线；嵌卡片内或末项关掉 | 写死有/无边 |
| 进度条 | Arco `a-progress`（percent 传 0–1、`animation`、size medium/small）；组件收 0–100 内部 `/100`；`#text` 显"进度 xx%" | 自绘 div 进度（浮标那种极细条除外，仍留调用方） |
| 状态色 | 复用 `docker/helpers.ts` 已有的 status→色口径，统一映射到 Arco progress status | 各页各定一套颜色 |
| 底部行 | `space-between` 左右分栏：左=ETA（剩余时间，“大约还需 x 分钟”，`--color-text-3`）/ 右=操作按钮（`#actions` 插槽 + 按 status 默认 取消/重试：running→取消，error/canceled→重试），emit `cancel/retry/open`；**有 meta/#meta 时与备注行合一行**（左备注 / 右 ETA+操作），不再多撑一行 | 把后端调用逻辑塞进组件（仍由调用方处理）；单靠右丢掉 ETA；备注与底部各占一行把卡片撑高 |
| 不定进度 | percent 缺省时**不猜百分比**：满宽条 + `meta` 显"已下 N MB / x 层" | 编一个假的百分比 |

## 三、状态映射（对齐 `docker/helpers.ts` 的 `statusKind`）

| 任务状态 | Arco `status` | animation | 备注文案示例 |
|---|---|---|---|
| idle / queued | `normal` | 否 | 排队中 |
| running / downloading | `normal` | 是 | 下载中 |
| stalled（有任务但久无新进度） | `warning` | 是 | 疑似卡住 |
| done / success | `success` | 否 | 已完成 |
| error / failed | `danger` | 否 | 失败：<原因> |
| canceled | `warning` | 否 | 已取消 |

> Arco `a-progress` 的 `status` 取值：`normal | success | warning | danger`。percent 语义为 0–1。

## 四、组件 API

`components/common/task-progress/index.vue`（新，`CommonTaskProgress`）

```ts
props: {
  name: string                 // 任务名（左，单行省略）
  status?: 'idle'|'running'|'done'|'error'|'canceled'|'stalled'
  percent?: number             // 0–100；缺省/undefined = 不定进度
  speed?: string              // 头行右侧，如 "1.2 MB/s"（tabular-nums）
  eta?: string                 // 底部行左侧：剩余时间，“大约还需 3 分钟”；空则不占位
  meta?: string                // 进度条下/旁的次要一行：阶段 / 备注 / "已下 3.2 MB/10 MB"
  size?: 'small'|'medium'      // 透传 a-progress
  showText?: boolean           // 进度条内文案，默认 true
  divided?: boolean            // 底部分隔线，默认 true
  variant?: 'plain'|'bare'     // 独立块 / 嵌卡片内
  clickable?: boolean          // 整行可点（emit click）
}
emits: ['click', 'cancel', 'retry', 'open']
slots:
  #name     覆盖名称区（放图标/tooltip/省略规则自定义）
  #extra    头行右侧（默认放 speed，可加连接数等）
  #left     底部行左侧（默认放 eta，可自定义为剩余字节/已传量/完成时间）
  #meta     覆盖备注行（展开失败原因等，保留 task-hub 现有的两行截断+展开）
  #actions  操作行（默认按 status 渲染 取消/重试/打开，靠右）
  #text     覆盖进度条文案（默认 "进度 {percent*100}%"，不定进度显 meta）
```

- 三段结构即用户草图：头行（`display:flex; justify-content:space-between`，名称 flex:1 省略 + 右侧速度不换行）→ **换行**整宽 `a-progress`（width:100%）→ **换行**底部行（`display:flex; justify-content:space-between; align-items:center`：**左=ETA 剩余时间**（`--color-text-3`，无则空占位）、**右=操作按钮**（`#actions`，靠右））。**有备注时底部行与备注行合成一行**：左=备注（flex:1，可挤压省略），右=ETA+操作（靠内容宽度）；无备注时备注整行独占、底部行退回左/右两栏。
- 颜色/字号一律用 CSS 变量（`--color-text-*`/`--color-border-2`/`--base-size-*`），不写死；跟随选中态/暗色。

### 适配 helper：`utils/taskProgress.ts`（新）
- `taskToProgress(t)`：把后端 `tasks.Task`（`ID/Title/Stage/Status/Percent/Note`）与 docker `DockerTask`（`speed/bytes/total/layers/doneLayers/retry/stalled`）归一成上面 props（status 词表统一、speedText 格式化、**eta 由 `speed`+`total-downloaded` 估算剩余时间**、actions 依 status）。调用方只写"数据→props"一次映射，不在模板里重复 `/100`、状态三元。
