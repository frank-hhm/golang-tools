## 二、前置事实（已核对，不是推测）

- `go.mod` **没有任何数据库**，加密侧只有 `golang.org/x/crypto/bcrypt`（`services/panel/settings.go`、`tools/ftp/server.go` 在用）；x/crypto 已在依赖，scrypt 可直接用
- 全仓无 cron 库，定时一律 `time.NewTicker`；`tools/downloader/engine.go` 已有「轮询到点的计划任务」写法可抄
- `tools/disk` 已导出 `List/Mkdir/NewFile/Rename/Copy/Move/PermanentDelete/DirSize/Search/SearchContent/Favorites/Drives/RecycleBin/RevealInExplorer/OpenShell/OpenTrash/OpenFile`，绑定 `DiskDelete(paths, permanent bool)` 已区分自建与系统回收站（Windows 走 SHFileOperation）
- `tools/launcher/index.go` 已有内存文件索引：`fileIndex` + `idxPtr.Load()` 原子替换 + `buildIndex(roots, maxEntries, maxDepth)` + `skipEntry`，是智能搜索的直接模板

- `tools/ftp/client_sftp.go` 的 `Preview`（`text|image|binary|tooLarge`）与 `previewTextMax/previewImageMax` 判定是远端预览现状；其 `*sftp.Client` 支持 `ReaderAt`，**远端 Range 可直接做**，不必先下载到临时文件

- 查看器已交付 `CodePane/ImagePane/PdfPane/SheetPane/MediaPane/BinaryPane`，磁盘与 FTP 本地栏的「打开」已改为优先经 `viewer:open-path` 事件进查看器单例窗

## 三、架构：只加两层

1. **`tools/docspace`（元数据与编排层）** —— 分类、标签、版本索引、回收站登记、加密登记、分享任务、备份计划。文件本体不动。
2. **`docref`（统一文件源）** —— 一个引用 = 源类型 + 会话 + 路径（`local` / `sftp` / `webdav` / `cloud`）。读、写、Range 流经它分发，于是预览/编辑/解压/播放对三种源同时生效，磁盘管理与文件传输只需交出一个 ref。

磁盘页与 FTP 页既有实现**不重构**（已稳定），只新增入口。

## 五、P1 组织与安全

## 十一、如实说明（选定路线的代价与不做清单）

- **docx 前端编辑保真有限**：图表、SmartArt、域代码、母版、批注样式会丢 —— 这是「前端可编辑」路线的既成事实，只能靠 mtime 回读 + 本机程序兜底缓解，不能靠调参解决
- **pptx 不做编辑**，仅预览；PDF 只做结构操作（`pdf-lib` 合并/拆分/注释），正文不可编辑
- **JSON 元数据规模上限**：建议单库 ≤ 2 万条目，超出后启动加载与搜索明显变慢；靠分片推迟，不靠换数据库
- **加密不是安全边界**：定位是防误看与防同步外泄，本机管理员仍可取明文
- **云盘与异地备份依赖外部账号**，现网接口随时可能变更（与 M7 既有判断一致）
- 不做：多人协作、在线 Office 服务、全文检索引擎、跨设备实时同步、DRM

## 十二、校验口径与顺序

1. `gofmt -l` 本次新写文件（`main.go`/`app.go`/`tasks.go` 是 CRLF，**禁止整文件 `gofmt -w`**）
2. `go vet ./tools/docspace ./tools/secstore ./tools/fileview ./tools/archive ./services/app`
3. `go test ./tools/docspace/... ./tools/secstore/... ./tools/fileview/... ./tools/archive/... -count=1` —— 覆盖：ref 编解码与越权路径、store 原子写与并发、版本快照与还原、回收站移入还原、分类改名后重挂、AES-GCM 往返与错口令、media 端点 `src=local` 与**旧参数兼容**、archive `List` 与 zip 内提取
4. `go build -o bin/_gt.exe .`（`go build .` 因 tools/ 大小写冲突不可用）
5. Linux 面板双构建：`$env:GOOS="linux"; $env:GOARCH="amd64"; $env:CGO_ENABLED="0"; go build -tags server -o bin/_linux_check .`
6. 前端：`npx vue-tsc --noEmit` → `npm run build`（vite 需 Node ≥20，用 `D:\nvm\v22` 直跑）；docx 编辑库必须 dynamic import，关注 >500kB 分包警告
7. 每期结束跑一次真机目视回归：分类树、回收站还原、版本回滚、docx 编辑保存回读、压缩包内预览
